
# TaskFlow

A full-stack task management application designed to help users organize, track, and manage their daily tasks efficiently.

## Project Overview

TaskFlow is a productivity application built with React and ASP.NET Core.

The project focuses on building a maintainable, secure, and scalable application using modern full-stack development practices.

## Technology Stack

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server

### Frontend
- React
- TypeScript
- React Router
- TanStack Query

### Tools & Practices
- Git & GitHub
- Docker
- Postman
- GitHub Actions
- Clean Architecture
- Automated Testing

## Project Goals

- Build a RESTful API for task management.
- Implement authentication and authorization.
- Develop a responsive React frontend.
- Integrate the frontend with the backend.
- Apply clean coding and architectural principles.
- Implement automated testing.
- Configure CI workflows using GitHub Actions.
- Use Docker for local development infrastructure.
